# Иллюстрации готовых сценариев

Для сценария **Too much salt** загрузите самостоятельно подготовленный JPG, например:

`assets/scenarios/salt/female-18-25-face.jpg`

Внешность должна быть тем же демо-персонажем до/после AI-обработки. Сценарная припухлость — художественная редактура, не эффект, предсказанный по продукту.

Поддерживаемые имена: `female` или `male`, затем `18-25`, `26-40`, `41-60` или `61-80`, затем `-face.jpg`.

Сценарии: `salt`, `fastfood`, `transfat`, `energy`, `balanced`, `sun`.

Если файла нет, Studio покажет обычный тестовый портрет и объяснит, что отдельная сценарная фотография не загружена. Не выдавайте исходный портрет за эффект от еды.

Для YouCam Skin Analysis нужен фронтальный крупный план: минимум 480 пикселей по короткой стороне для SD, лицо занимает значительную долю ширины кадра (>60% согласно требованиям провайдера), без сильного затенения, прядей на лице или размытия. Идеально подойдут отдельные близкие кадры, подготовленные из того же художественного персонажа. Результат не является медицинской диагностикой.
