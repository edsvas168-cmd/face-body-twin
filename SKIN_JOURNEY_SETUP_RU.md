# Новый Face Twin: сценарий → анализ кожи → подбор ухода → AI-улучшение
Дата подготовки: 31 октября 2026.

## Реализовано в коде
- На странице `/studio/` появился блок из четырёх этапов, на русском.
- Сценарная фотография ищется в `/assets/scenarios/{scenario}/{gender}-{age}-face.jpg`. Если файла нет, показывается исходный персонаж с честным предупреждением.
- Кнопка «Анализировать кожу через API» вызывает серверный `/api/skin-journey-start` с `action=analyze` → YouCam `POST /s2s/v2.1/task/skin-analysis`.
- Запрос использует SD-признаки: тип кожи, увлажнённость, текстура, покраснение, высыпания, область под глазами, тёмные круги, сияние, жирность, поры. `format=json`. HD и SD не смешаны.
- Статус: `/api/skin-journey-status` → `GET /s2s/v2.1/task/skin-analysis/{task_id}`, результат разбирается в безопасные пользовательские баллы, если они есть.
- По полученным баллам **наш собственный код** выбирает категории средств: мягкое очищение, безотдушечный/некомедогенный/церамидный увлажняющий крем по ситуации, широкоспектральный SPF 30+. Нет выдуманных брендов или ссылок на покупку. Не утверждаем, что YouCam бесплатно выдаёт готовый каталог продуктов.
- После успешного анализа доступна кнопка «Улучшить кожу через API» → `POST /s2s/v2.0/task/skin-simulation`: умеренные `eye_bags`, `dark_circle`, `redness`, `texture`, `radiance`, и показ **реального** результата при успешном ответе YouCam.
- Старые Face Reshape endpoint'ы по умолчанию отключены `410` для предотвращения случайных списаний.
- В личных фото никаких запросов к YouCam нет. Необходимы тестовый персонаж, согласие, секретный доступ, включённый серверный флаг.
- Тестовые функции для построения payload и безопасного разбора добавлены в `tests/skin-journey.test.js`.

## Что нужно для завершения

### 1. Готовое сценарное фото
Сделайте **отдельную** фотографию персонажа с лёгкой припухлостью щёк и зоны под глазами: это художественная редактура, не реальный эффект от соли. Оставьте ту же личность, взгляд, масштаб, фон, освещение; лицо должно занимать большую часть кадра. JPG, минимум 480 пикселей по короткой стороне, лучше крупное фронтальное лицо.

Для одного теста загрузите файл в GitHub:
`assets/scenarios/salt/female-18-25-face.jpg`

На Studio выберите **Woman → 18–25 → Too much salt**. Если картинка загружена, сайт обнаружит её и будет использовать как вход YouCam. Для других персонажей и сценариев нужно добавить их собственные изображения с аналогичными названиями.

**Важно:** анализ отредактированной фотографии будет оценкой изображения искусственного персонажа. Он не определяет, сколько соли было съедено, и не является диагностиками человека.

### 2. Секреты в Vercel
Создайте **новый** ключ YouCam (ранее раскрытый ключ следует отозвать в панели API). В Vercel → Project → Settings → Environment Variables:
- `YOUCAM_API_KEY` = новый секретный ключ (НИКОГДА не загружать в GitHub, скрин или клиентский JS)
- `YOUCAM_DEMO_ACCESS_CODE` = отдельный случайный секретный пароль длиной 16+ символов
- `YOUCAM_DEMO_ENABLED` = `true` **только для закрытого теста**
- `YOUCAM_LEGACY_ENABLED` оставить неустановленным / `false`
Затем redeploy, если это требуется Vercel.

### 3. Проверка на демо-персонаже, с вашим согласия на расход units
Сначала проверьте текущий баланс и стоимость одного вызова на официальной странице:
https://yce.makeupar.com/api-console/en/api-keys/
Документация по free cost checks: https://docs.perfectcorp.com/develop/agent_skills

В Studio выберите модель и сценарий → согласие → введите тестовый код → «Анализировать кожу через API». После реальных оценок (если YouCam вернул) изучите уход и только затем «Улучшить кожу через API». Это **два отдельных потенциально платных API-запроса**, оба вызываются только после клика. Не запускайте повторно при задержке, пока не проверите консоль YouCam.

**Не проверено в живом API:** разрешения ключа на v2.1 skin-analysis, точный формат `format=json` для реальных фотографий, качество/пригодность изображений, итог Skin Simulation, веб-страница после сборки Vercel и расход units. Код прошёл синтаксический контроль и локальные логические проверки без расхода единиц.

### 4. Перед публичным запуском
Пока `YOUCAM_DEMO_ENABLED` лучше оставить `false`. Нужны: постоянные лимиты по пользователю/IP, финансовый потолок расхода, хранение подтверждённого согласия, правила приватности и удаления реальных фото, если когда-нибудь разрешим персональные снимки.

## Медицинские и продуктовые границы
- YouCam Skin Analysis не определяет причины отёка и не связывает его с питанием.
- Уходовые средства способны улучшать вид кожи, но **не лечат отёчность от потребления натрия**.
- Skin Simulation создаёт **косметическую визуализацию**; она не доказывает реальное восстановление кожи или эффект выбранных средств.
- При неожиданном, сильном или сохраняющемся отёке требуется медицинская оценка.
- Product recommendation SaaS для конкретных брендов требует отдельной интеграции каталога и, возможно, других коммерческих разрешений. В MVP реализованы понятные категории средств по фактическим оценкам API.
