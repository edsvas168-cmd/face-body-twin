# Face & Body Twin — актуальное состояние проекта

**Позиционирование:** «Разберись с трендами о еде и внешности — с цифрами, а не с мифами».

## Что в GitHub
- Главная: один крупный блок с иллюстрацией лица «до/после», без карточки Body Twin; раздел «цифры вместо мифов» заменяет описания изменений тела.
- Studio: только Face Twin, без выбора Face / Body. Поддерживаются демонстрационные лица, сценарии питания, ручной ввод и образовательные пояснения.
- Четыре языка на главной; ключевые статические элементы Studio также переведены. Динамические сообщения Studio пока остаются преимущественно на английском.
- Калькулятор нутриентов и движок условных сценариев вынесены в `shared/`.
- Приватная интеграция YouCam подготовлена в `api/`, но не тестировалась с реальным ключом и выключена по умолчанию.
- Текст для Devpost подготовлен в `DEVPOST_DESCRIPTION.md`, **не опубликован на Devpost автоматически**.

## Ограничения
Визуальный пример не является прогнозом последствий еды. Неизвестные нутриенты отмечаются. Фотографии пользователя остаются локальным превью; внешняя обработка с личными фото не настроена. Визуальные эффекты YouCam и развёртывание в браузере ещё требуют отдельной проверки.

**Roadmap:** Face-focused MVP; body visualization — roadmap.
